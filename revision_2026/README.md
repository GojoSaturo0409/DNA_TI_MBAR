# Revised calculations (2026 revision)

Data and code for the revised manuscript (tx-2026-004943, *Chem. Res. Toxicol.*):
two-stage TI/MBAR decoupling of four motifs (lesion 602, partner bases 584-585, BHD2 tip 392-406,
BHD3 tip 475-485) in the docked and productively bound Rad4-DNA complexes, for the 6-4PP and the CPD lesion
(16 legs, 63 lambda windows x 10 ns each). These results replace the original single-stage, 12-window
calculations in `../TI_DATA/TI_simulations/`, which are kept only for reference.

## Contents

| folder | content |
|---|---|
| `topologies/` | AMBER topologies of the four complexes (`64pp_bound`, `64pp_docked`, `cpd_bound`, `cpd_docked`), CPD coordinates and CPD residue parameters (`cpd.prepi`, `cpd.frcmod`). `MD5SUMS`: the checksums enforced by the production jobs. The CPD complexes differ from the 6-4PP ones only in residue 602. |
| `seeds/<system>_<state>_<motif>/seed_lambda0.5.rst7` | Equilibrated starting structure of every leg (lambda = 0.5); every window starts from it at its own lambda. |
| `inputs/` | `template_E.in` (stage E, linear decharging, no soft-core), `template_V.in` (stage V, soft-core vdW, `scalpha=0.2`), single-point inputs `sp_E.in`/`sp_V.in`, lambda schedules (`lambdas_bhd2dense.csv`: window, stage, lambda, Gauss-Legendre weight; weight 0 = MBAR-only window). |
| `jobs/` | Seed equilibration (`stageA3.sbatch`: restrained/unrestrained/lambda=0.5 minimization, 200 ps heating, 500 ps NVT, 2.4 ns NPT) and window jobs (`prod2c*.sbatch`: 5 ns run, extension to 10 ns, dense windows). Slurm specifics (partition, node lists) must be adapted to your cluster. |
| `analysis_scripts/` | `extract_dvdl.py`, `extract_s3.py`, `extract_s4.py` (DV/DL and single-point energies from AMBER outputs), `assemble_*.py` (63 x 10 ns data sets), `analyse_2stage_v3.py` (TI + MBAR, overlap, paired block bootstrap, convergence), `summarise_legs.py` (per-leg tables, Rocklin, ddG), `endstate_entropy.py` (dU and -TdS per stage), `compare_lengths.py` (5 vs 10 ns), `run_rocklin.py`/`run_all.sh` (finite-size correction), `welch.py`/`perrep_metrics.py` (Welch tests on unbiased MD), `make_si_tables.py` (SI tables). |
| `data/dvdl/<system>/<system>_<leg>.tar.gz` | Per-window `dU/dlambda` time series (`wNN_dvdl.txt`, `wNN_s3_dvdl.txt` for the 5-10 ns extension) and stage-V single-point energies at all 32 vdW states (`wNN_sp_energies.txt`, `wNN_sp3_energies.txt`), 63 windows x 10 000 points per leg. |
| `results/<system>/` | Per-leg analysis JSON (`*_2stage.json`: TI, MBAR, errors, overlap, forward/reverse, checks), overlap matrices (`*_overlap.npy`), summaries (`summary_*`). `results/endstate/`: energy/entropy split. `results/convergence_5ns_vs_10ns/`. Welch tests and matched B-factors. |
| `rocklin/` | Rocklin et al. (2013) correction per leg: APBS input, `rocklinc` log and the resulting correction (`rocklin_all_legs.tsv`). APBS grids are not included (13 GB); they are regenerated by `run_rocklin.py`. |

## Reproducing the main numbers

```bash
# 1. unpack the DV/DL data of one leg
mkdir -p runs && tar xzf data/dvdl/64pp/64pp_pb_lesion.tar.gz -C runs
# 2. TI + MBAR for that leg
python analysis_scripts/analyse_2stage_v3.py runs/pb_lesion inputs/lambdas_bhd2dense.csv out --label 64pp_pb_lesion --dense
# 3. after all 8 legs of a system: per-leg table, Rocklin correction and ddG
python analysis_scripts/summarise_legs.py out 64pp rocklin/rocklin_all_legs.tsv out/summary_64pp
```
Requirements: Python 3.11+, numpy, scipy, pandas, pymbar 4.x; AMBER 24 (`pmemd.cuda`) for the simulations; APBS + rocklinc for the finite-size correction.

Sign convention: ddG(m) = dG_dec,corr(m, bound) - dG_dec,corr(m, docked); ddG > 0 means that motif m interacts more favourably with its surroundings in the bound complex.

Trajectories (several hundred GB) are available from the authors on request.
