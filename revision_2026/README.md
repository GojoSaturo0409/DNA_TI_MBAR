# Revised calculations (2026 revision)

Data and code for the revised manuscript (tx-2026-004943, *Chem. Res. Toxicol.*):
two-stage TI/MBAR decoupling of four motifs (lesion 602, partner bases 584-585, BHD2 tip 392-406,
BHD3 tip 475-485) in the docked and productively bound Rad4-DNA complexes, for the 6-4PP and the CPD lesion
(16 legs, 63 lambda windows x 10 ns each). These results replace the original single-stage, 12-window
calculations in `../TI_DATA/TI_simulations/`, which are kept only for reference.

## Contents

| folder | content |
|---|---|
| `topologies/` | AMBER topologies of the four complexes (`64pp_bound`, `64pp_docked`, `cpd_bound`, `cpd_docked`), CPD coordinates and CPD residue parameters (`cpd.prepi`, `cpd.frcmod`). `MD5SUMS`: the checksums enforced by the production jobs. The CPD complexes differ from the 6-4PP ones only in residue 602. |
| `seeds/<system>_<state>_<motif>/seed_lambda0.5.rst7` | Equilibrated starting structure of every leg (lambda = 0.5); every window starts from it at its own lambda. |
| `inputs/` | `template_E.in` (stage E, linear decharging, no soft-core), `template_V.in` (stage V, soft-core vdW, `scalpha=0.2`), single-point inputs `sp_E.in`/`sp_V.in`, lambda schedules (`lambdas_bhd2dense.csv`: window, stage, lambda, Gauss-Legendre weight; weight 0 = MBAR-only window). |
| `jobs/` | Seed equilibration (`stageA3.sbatch`: restrained/unrestrained/lambda=0.5 minimization, 200 ps heating, 500 ps NVT, 2.4 ns NPT) and window jobs (`prod2c*.sbatch`: 5 ns run, extension to 10 ns, dense windows). Slurm specifics (partition, node lists) must be adapted to your cluster. |
| `analysis_scripts/` | `extract_dvdl.py`, `extract_s3.py`, `extract_s4.py` (DV/DL and single-point energies from AMBER outputs), `assemble_*.py` (63 x 10 ns data sets), `analyse_2stage_v3.py` (TI + MBAR, overlap, paired block bootstrap, convergence), `summarise_legs.py` (per-leg tables, Rocklin, ΔΔF), `endstate_entropy.py` (dU and -TdS per stage), `run_rocklin.py`/`run_all.sh` (finite-size correction), `welch.py`/`perrep_metrics.py` (Welch tests on unbiased MD), `make_si_tables.py` (SI tables). |
| `data/dvdl/<system>/<system>_<leg>.tar.gz` | Per-window `dU/dlambda` time series (`wNN_dvdl.txt`, `wNN_s3_dvdl.txt` for the 5-10 ns extension) and stage-V single-point energies at all 32 vdW states (`wNN_sp_energies.txt`, `wNN_sp3_energies.txt`), 63 windows x 10 000 points per leg. |
| `results/<system>/` | Per-leg analysis JSON (`*_2stage.json`: TI, MBAR, errors, overlap, forward/reverse, checks), overlap matrices (`*_overlap.npy`), summaries (`summary_*`). `results/endstate/`: energy/entropy split. Welch tests and matched B-factors. |
| `unbiased_md/` | Unbiased MD (4 × 50 ns per complex, 6-4PP and CPD; see below). |
| `manuscript_figures/` | Scripts that produce every figure and table of the manuscript and SI from the data in this folder (see the map below). |
| `rocklin/` | Rocklin et al. (2013) correction per leg: APBS input, `rocklinc` log and the resulting correction (`rocklin_all_legs.tsv`). APBS grids are not included (13 GB); they are regenerated by `run_rocklin.py`. |

## Reproducing the main numbers

```bash
# 1. unpack the DV/DL data of one leg
mkdir -p runs && tar xzf data/dvdl/64pp/64pp_pb_lesion.tar.gz -C runs
# 2. TI + MBAR for that leg
python analysis_scripts/analyse_2stage_v3.py runs/pb_lesion inputs/lambdas_bhd2dense.csv out --label 64pp_pb_lesion --dense
# 3. after all 8 legs of a system: per-leg table, Rocklin correction and ΔΔF
python analysis_scripts/summarise_legs.py out 64pp rocklin/rocklin_all_legs.tsv out/summary_64pp
```
Requirements: see `requirements.txt` (exact versions used); Python 3.12, AMBER 24 (`pmemd.cuda`) for the simulations; APBS + rocklinc for the finite-size correction.

Sign convention: ΔΔF(m) = ΔF_corr(m, bound) − ΔF_corr(m, docked); ΔΔF > 0 means that motif m interacts more favourably with its surroundings in the bound complex.

Trajectories (several hundred GB) are available from the authors on request.


## Unbiased MD (`unbiased_md/`)

| folder | content |
|---|---|
| `setup/` | tleap inputs (`leap_pb.in`, `leap_docked.in`), the three-step relaxation inputs (`min1-3_*.in`) and the scripts used to build the CPD complexes from the 6-4PP models by replacing residue 602 (`map.py`, `mkpdb2.py`, `final.py`). |
| `protocol/` | Equilibration and production jobs of the CPD complexes (`cpd_equil.sbatch`, `cpd_prod.sbatch`: 50 ns, NPT, 300 K, 1 bar, Langevin γ = 2 ps⁻¹, Berendsen barostat, 2 fs with SHAKE on bonds to H, 10 Å cutoff, PME). |
| `data/<lesion>/` | Per-frame collective variables and SASA of all four replicas (`cv_sasa_<state>.csv`), per-replica means, pseudodihedral time series (`dihedrals/`) and per-replica MSD(τ) and COM-displacement time series (`msd_rmsd/`). |
| `analysis_scripts/` | `perrep_metrics.py` (per-replica RMSF/RMSD), `welch2.py` (Welch t-tests with Holm correction, Table 2 and SI Table S10), `rmsf_res.py` (per-residue RMSF, SI Figure S14), `elec_res.py` (residue-level BHD2 electrostatics, SI Table S12), `lesion_discrim.py` (CPD vs 6-4PP discrimination, SI Figure S5), `net_engine.py`/`net_post.py` (interaction fingerprints, clustering, residue network, contact lifetimes, DCC; Figure 7, SI Figures S6, S7, S15, S16), `bfactors.py` (B-factors of 6CFI and 2QSG on the simulated motifs, SI Table S11). |
| `results/` | Outputs of these scripts; `network/` holds clusters, network metrics, contact lifetimes, DCC blocks, interaction-fingerprint occupancies (per replica) and lesion specificity. |

Trajectories (4 complexes × 4 replicas × 50 ns, and all TI windows) are several hundred GB and are available from the authors on request.

## Reporting checklist (JCIM guidelines for MD simulations, Soares et al. 2023, doi:10.1021/acs.jcim.3c00599)

| item | where |
|---|---|
| Software and versions | AMBER 24 (`pmemd.cuda`), AmberTools; APBS + rocklinc; Python packages in `requirements.txt` |
| Force fields and custom parameters | ff14SB, parmbsc1, TIP3P; lesion parameters in `topologies/` (`cpd.prepi`, `cpd.frcmod`) and in the topologies |
| Starting structures and modelling | PDB 6CFI, 2QSG, 1CFL; models in `../structures/` and `topologies/`; build scripts in `unbiased_md/setup/` |
| System composition (water, ions, box) | `topologies/` (SI Table S1) |
| Minimization, equilibration and production protocol | `jobs/` (TI), `unbiased_md/setup/`, `unbiased_md/protocol/` |
| Input files for every run | `inputs/`, `jobs/`, `unbiased_md/` |
| Equilibrated starting coordinates | `seeds/` (TI legs) |
| Number and length of replicas | 63 windows × 10 ns per TI leg; 4 × 50 ns unbiased MD per complex |
| Convergence and uncertainty | `results/<system>/*_2stage.json` (overlap, forward/reverse, halves, paired block bootstrap) |
| Raw data behind figures and tables | `data/`, `results/`, `unbiased_md/` (map above) |
| Analysis code | `analysis_scripts/`, `unbiased_md/analysis_scripts/`, `manuscript_figures/` |
| Trajectories | on request (size) |
